# SILI QQ 聊天管理页

## 目标

让管理员在现有 Koishi 控制台查看 QQ 机器人实际收到和发出的聊天，并从会话里直接管理相关的人和群。

## 范围

- 群聊和私聊的活跃会话、实时消息、历史翻页、引用和常见消息元素。
- 会话右上角菜单提供配置。群内可搜索有记录的发言者并打开用户配置。
- 以 QQ 机器人身份向当前会话发送纯文本。

## 决定

1. 在 QQ 频道管理插件中新增「QQ 聊天」页面，沿用控制台登录和四级权限。左侧是会话列表，右侧是聊天区，窄屏在两者之间切换。
2. 会话按最近一次收发排序。历史和新消息都来自 `channel_message`，按机器人和频道隔离，沿用现有记录范围和保留时间。控制台连接推送活动信号，页面重新同步最新一页，滚动回看时保留位置。
3. 群配置和私聊配置沿用激活状态和功能覆写。用户面板复用频道管理的 Koishi 权限编辑与权限检查。成员列表来自 `qqbot_member`，只列机器人记录过的发言者。
4. 正文按允许的 Koishi 元素展示，链接和媒体只接受安全的网络地址。引用在同一会话内解析，超出记录范围的引用显示为不可用。
5. 发送必须按住发送按钮或回车满 600 毫秒。提前松开、失焦、切换会话或取消手势会中止。输入法选词和 Shift+Enter 不触发发送。发送前在服务端核对当前会话可服务和群主动发送权限，交给 QQ 适配器主动发送。失败时保留文字供手动重试。

## 验收

- 新的 QQ 收发会更新会话列表和当前聊天。翻页没有重复，同秒消息齐全，查看旧消息时新消息不会拉走滚动位置。
- 群聊里能找到指定成员并进入对应人的设置。配置刷新后显示真实保存结果。
- 短按或取消不会发送。按住达标只发送一次，成功后在会话记录里出现。群关闭主动发送时清楚说明原因。
- 未登录或权限不足无法读取聊天和成员数据、接收活动信号或发送消息。
