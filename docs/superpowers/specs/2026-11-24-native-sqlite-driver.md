# SILI 原生 SQLite 驱动

## 目标

在 SILI 仓库内维护兼容 Minato 3.6 的 SQLite 驱动，让 Koishi 可以使用 Bun 的原生 SQLite 引擎。

## 决定

- 以官方 `@minatojs/driver-sqlite@4.6.0` 为基线，参考 `5.0.3` 移植 `node:sqlite` 绑定。保留 MIT 许可和上游版本出处。
- 沿用 Minato 3 的接口、SQL 生成、表结构、索引和数据类型映射。原生驱动使用现有 SQLite 文件、单连接和当前的连接行为。
- `SILI_DATABASE=sqlite` 下用 `SILI_SQLITE_DRIVER=native` 选择原生版，默认值为 `wasm`。恢复默认值即可用官方驱动读取同一个库。
- SQLite 定时备份沿用现有信号、文件路径、完整性检查和 R2 工作流。原生连接负责生成快照。

## 验收

- 用部署容器中的 Bun，在 Noir 最新 SQLite 快照副本上检查表、索引、记录和外键设置，并核对两种驱动查询结果。
- 覆盖消息分页、`@` 查询、引用、主键去重、插入和事务回滚。用同一批查询及写入对照 P50 和 P95。
- 从原生运行实例请求快照，在独立文件恢复并做完整性检查。用旧驱动重新打开原生写过的库，核对结果。
