# SILI native SQLite driver

Forked from the MIT-licensed [Minato SQLite driver 4.6.0](https://github.com/cordiverse/database/tree/2e0327ad452cc1383f989af80d9d1bc676963755/packages/sqlite).
The binding follows [Minato SQLite driver 5.0.3](https://github.com/cordiverse/database/tree/fd2ddb1722405f72b06965eea06f846abf67dbbe/packages/sqlite).
See [LICENSE](LICENSE) for the upstream copyright and license.

With `SILI_DATABASE=sqlite`, set `SILI_SQLITE_DRIVER=native` to enable this driver.
Unset the variable or set it to `wasm` to use the official 4.6.0 driver with the same database file.
